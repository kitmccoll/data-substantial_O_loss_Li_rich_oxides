[![DOI](your-doi-badge)](your-doi-link)

Data and analysis scripts for the computational results in:

**Substantial Oxygen Loss and Chemical Expansion in Lithium-Rich Layered Oxides 
at Moderate Delithiation**  
P.M. Csernica, K. McColl et al. — *Nature Materials* 24, 92–100 (2025)  
[https://doi.org/10.1038/s41563-024-02032-6](https://doi.org/10.1038/s41563-024-02032-6)

## Repository structure

- `Data/` — DFT-calculated structures, energies, and forces
- `Analysis/` — Jupyter notebooks to reproduce all computational figures
